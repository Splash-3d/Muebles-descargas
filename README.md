# Muebles: descargas

Diseñador de cocinas **Muebles**.

**Windows 10/11 (64 bits):** https://github.com/Splash-3d/Muebles-descargas/releases/latest/download/Muebles-instalador.exe

No está firmado: si Windows muestra «Windows protegió su PC», pulsa «Más información» y luego «Ejecutar de todas formas».

**Móvil Android:** https://github.com/Splash-3d/Muebles-descargas/releases/latest/download/Muebles.apk

Ábrelo desde el móvil; te pedirá permitir «instalar apps de origen desconocido» para el navegador o el gestor de archivos. Abre y guarda ficheros .cocina, igual que en el PC.
